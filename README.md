The one word to erase from the dictionary forever:

> word

A dictionary is a book made entirely of words. Erase the word "word" and the book can no longer name what it is made of — every entry in it is a word, yet the word for "word" itself is gone. The program in `main.ts` writes that single word (4 characters) to `entry.txt` in the output directory, after checking it fits the bounty gate: one word, 1–77 characters, nothing else attached.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
